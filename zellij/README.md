# zellij

Configuration for [Zellij](https://zellij.dev/), the current terminal
multiplexer.

Deployed path: `zellij/.config/zellij/config.kdl` → `~/.config/zellij/config.kdl`.
A `config.kdl.bak` is kept alongside as a snapshot of a prior autogenerated
config.

## Current state

- **Active — the multiplexer in daily use.** Replaced tmux as the primary
  multiplexer (see the `tmux/` package, retained as legacy/backup).
- Custom keybindings with `clear-defaults=true` — the config defines its own
  bindings rather than layering on Zellij's defaults.
- Locked mode toggled with `Ctrl g`; pane navigation with Vim-style `h/j/k/l`
  plus arrow keys.

## Features

- Vim-style pane focus movement (`h/j/k/l`).
- Pane management: split down (`d`), split right (`r`), stacked (`s`), new (`n`),
  fullscreen toggle (`f`), floating toggle (`w`), embed/float (`e`), pin (`i`),
  frames toggle (`z`).
- Rename pane mode (`c`).
- One Dark theme for visual consistency with the rest of the environment.

## Goal

Zellij is the working multiplexer **today**, but the environment is migrating to
[Herdr](https://herdr.dev/) — an agent-aware multiplexer that adds persistent
PTY sessions, semantic agent state (blocked/working/done), and remote SSH attach
(including from a phone). See [AGENTS.md](../AGENTS.md) section 11 for the
migration context.

Until Herdr is configured and adopted, Zellij stays the daily multiplexer. When
the migration completes, this package is retained for reference/rollback (the
same way `tmux/` is kept now).

## Migration reference

A `zellij` → `herdr` keybinding/command cheat sheet will be produced as part of
the Herdr setup and lives with the `herdr/` package once created.
